# Contributing to BioHuman

Thank you for your interest in contributing!

## Getting Started

1. **Fork the repository:** Start by forking this repository to your own GitHub account.
2. **Create a branch:** Create a new branch for your feature or bugfix (e.g., `feature/new-button` or `fix/header-alignment`).
3. **Commit your changes:** We follow Conventional Commits style for commit messages. Please ensure your commits clearly describe the changes.
4. **Run tests before opening a PR:** Before submitting your pull request, please run all checks and tests locally.

```sh
pnpm install --frozen-lockfile
pnpm run check
pnpm run type-check
pnpm vitest run
pnpm run build
```

5. **Open a Pull Request:** Open a pull request against the `main` branch with a clear description of your changes.

Thank you!
