# Security Policy

## Supported Versions

| Version           | Supported          |
| ----------------- | ------------------ |
| Latest Release    | :white_check_mark: |
| Default branch    | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories. You can do this by navigating to the "Security" tab of this repository and clicking on "Report a vulnerability". **Do not open public issues for security reports.**

## Response Targets

- **Acknowledgement:** We aim to acknowledge your report within 5 business days.
- **Status Update:** We aim to provide a status update within 14 days.

## Disclosure Policy

We practice coordinated disclosure. Please allow us time to investigate and patch the vulnerability before disclosing it publicly.

## Bug Bounty

We do not currently offer a bug bounty program.
